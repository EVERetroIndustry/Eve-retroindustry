What's in it

Built for a multi-character industry career, not a single pilot.

Blueprints to raw materials

Recursive expansion through components and reactions, with your own ME/TE per blueprint.

Make-vs-buy that counts fees

Only builds a component when materials plus the job install fee actually beat buying it.

Real market data

Live ESI prices for Jita, the trade hubs and any station or citadel, cached locally.

Your assets counted in

Character and corporation hangars, containers and divisions — so the shopping list is what you're actually missing.

Structures and rigs

Raitaru to Sotiyo, Athanor to Tatara, with per-slot rigs and the right security multiplier.

Jobs, orders, contracts, wallet

Industry slots in use, open orders with what's still on the market, and a searchable public contract index.

Planetary interaction

Extractor countdowns, factory chains and an estimated value per day, with alerts before a program expires.

Projects

Save a plan, tick off finished jobs, and keep one shopping list across a multi-stage build.

Before you install

Two things worth knowing before you start.

First run
Windows shows a blue warning screen — that's expected

You'll see “Windows protected your PC”. It isn't a virus alert: Windows says this about any program from a small developer who hasn't bought an expensive certificate. Click More info, then Run anyway — just the once, not every time.

Want to check the file first? Each download on the release page lists a checksum you can compare, and the whole source code is public.

Privacy
Nothing is uploaded anywhere

Your characters, prices and projects stay in a file on your own computer — there's no account to create and no server of mine involved. The app talks only to EVE's own servers, to read your game data and to log you in. Uninstalling leaves your data untouched.

Something broken or missing? Open an issue on GitHub, or just email everetroindustry@gmail.com.

Free, and staying that way

Built for my own EVE career and shared as-is. If it saves you ISK or an evening of spreadsheets, a coffee is a nice way to say so — entirely optional.
